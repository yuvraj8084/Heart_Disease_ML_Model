# ❤️ Heart Disease Prediction using Machine Learning

## 📌 Project Overview

This project is a **Machine Learning-based Heart Disease Prediction System** developed to predict whether a person is likely to have heart disease based on different health and clinical parameters.

The project demonstrates a complete Machine Learning workflow, including **data preprocessing, exploratory data analysis, feature encoding, feature scaling, model training, evaluation, and deployment using Streamlit**.

The trained model takes patient-related information as input and provides a prediction through an easy-to-use web interface.

## 🎯 Objective

The main objective of this project is to understand how Machine Learning can be applied to healthcare-related datasets to identify patterns associated with heart disease.

It also demonstrates how a trained ML model can be integrated into a **user-friendly web application** for making predictions.

## 📊 Features Used

The model uses several important health-related features:

* **Age** – Patient's age
* **Sex** – Gender of the patient
* **Chest Pain Type** – Type of chest pain experienced
* **Resting Blood Pressure** – Blood pressure at rest
* **Cholesterol** – Cholesterol level
* **Fasting Blood Sugar** – Fasting blood sugar condition
* **Resting ECG** – Resting electrocardiogram result
* **Maximum Heart Rate** – Maximum heart rate achieved
* **Exercise-Induced Angina** – Whether exercise causes angina
* **ST Slope** – Slope of the ST segment during exercise

## 🤖 Machine Learning Model

The project uses the **K-Nearest Neighbors (KNN)** classification algorithm to predict heart disease.

Before training, the dataset is processed using appropriate preprocessing techniques such as:

* Handling missing or inconsistent data
* Encoding categorical features
* Splitting data into training and testing sets
* Feature scaling using `StandardScaler`
* Training and evaluating the ML model

The trained model is saved using **Joblib** and reused by the Streamlit application.

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone <your-repository-link>
```

### 2. Install required libraries

```bash
pip install -r requirements.txt
```

### 3. Run the Streamlit application

```bash
streamlit run app.py
```

After running the command, the application will open in your browser.

## 💡 Application

The Streamlit application provides an interactive interface where users can enter patient information such as age, blood pressure, cholesterol, chest pain type, maximum heart rate, and other parameters.

Based on the provided inputs, the trained KNN model generates a heart disease prediction.
